# Code of Conduct

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and accept constructive feedback, and do not harass or
discriminate against anyone. Maintainers may remove comments, commits and contributions that violate this
code, and may ban repeat offenders.

To report a problem, open a private security advisory on this repository or contact the maintainers
through the repository owner's GitHub profile.
