# RelayNest Design and Image Generation Prompts

Use these prompts to generate visual references. Treat generated mockups
as design inspiration, not production UI source.

## Shared visual direction

Premium developer-focused SaaS. Dark-first interface, #09090B
background, #18181B cards, #27272A borders, #635BFF primary accent,
#8B5CF6 secondary accent, modern sans-serif typography, restrained
gradients, clear hierarchy, polished spacing, accessible contrast,
realistic product UI.

## Logo icon

Create a minimalist geometric vector-style symbol for RelayNest, a
Telegram bot and workflow automation SaaS. Combine an abstract letter R
with connected network nodes and a routing motif. Use electric violet
#635BFF and subtle purple #8B5CF6 on a dark #09090B background.
Distinctive silhouette, flat design, scalable, no text, no mockup, no
watermark.

## Logo with wordmark

Create a horizontal brand lockup for RelayNest. Place the geometric
automation/network icon to the left of the wordmark "RelayNest". Use
modern geometric sans-serif typography, medium-bold weight, violet
accent, dark background. Crisp, minimal, balanced, no extra text, no
mockup.

## Favicon

Create a square 1:1 favicon using only the RelayNest geometric R/network
symbol. High contrast, simple silhouette, violet #635BFF on dark
#09090B, centered, no text, legible at 16x16 pixels.

## Landing page

Design a high-fidelity 16:9 desktop landing page for RelayNest, a
no-code Telegram bot and workflow automation SaaS. Include navigation,
hero headline "Automate Your Telegram. Simplify Your Workflow.", Get
Started Free and Explore Templates buttons, realistic dashboard preview,
Telegram notification preview, feature cards, template gallery,
how-it-works section, AI Coming Soon section, FAQ, and footer. Use the
shared visual direction.

## Dashboard overview

Design a production-quality RelayNest dashboard with collapsible left
sidebar, top header, workspace switcher, search, notifications, profile
menu, KPI cards for Total Bots, Active Bots, Agents, Executions and
Failed Executions, recent activity, recent executions, bot performance,
and quick actions. Use realistic but clearly illustrative data.

## Bot management

Design a Bot Management screen with search, status filters, Create Bot
button, and cards for Support Bot, GitHub Notifications, Welcome Bot,
and Server Monitoring Bot. Cards show bot avatar, username, status,
webhook state, activity, and management actions.

## Bot creation wizard

Design a multi-step bot wizard with steps Bot Information, Telegram
Connection, Commands, Responses, and Review & Deploy. Show a masked
token field, validation button, bot profile preview, and clear security
helper text.

## Workflow builder

Design a wide desktop node-based workflow editor. Include left node
library (Triggers, Conditions, Actions), central grid canvas with
connected nodes (GitHub Webhook → Event Type Condition → Telegram Send
Message), right configuration panel, and top toolbar with Save, Test
Workflow, and Activate. Use clear node labels and realistic connection
handles.

## Telegram integration

Design a Telegram integrations screen showing connected bots, usernames,
Telegram IDs, connection status, webhook status, last sync, Validate
Token, Connect New Bot, and Configure Webhook actions. Include a simple
Telegram-to-RelayNest webhook illustration.

## AI Coming Soon

Design an AI Platform dashboard section with disabled cards for AI Agent
Builder, Model Providers, Knowledge Base, RAG Search, Milvus
Integration, Local Ollama Models, and Cloudflare AI Gateway. Each card
has a Coming Soon badge and concise description. Make it clear these
features are not available yet.
